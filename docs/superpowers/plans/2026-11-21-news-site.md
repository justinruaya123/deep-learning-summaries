# News Site Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:executing-plans. Steps use checkbox syntax for tracking.

**Goal:** Publish the approved dark news feed and readable weekly articles on GitHub Pages.

**Architecture:** Generate static docs/ HTML from summaries/ Markdown and sources/ JSON. Serve local CSS and one small filter module. GitHub Pages publishes committed output; no runtime service.

**Tech Stack:** Python, Markdown==3.11.3, semantic HTML, CSS, vanilla JavaScript, unittest, Node test runner.

**Spec:** docs/superpowers/specs/2026-11-21-news-site-design.md

## Global Constraints
- Preserve all existing factual content and caveats; 22 current developments, 31 sources.
- No analytics, external scripts/fonts, backend, recurring research job, or synthesized news.
- All site links work beneath the project subpath and without JavaScript for reading.
- User approved native execution and publishing in chat ("Build and publish it now").

## Review Focus
- Citation fragments and deep story links resolve on GitHub project URLs.
- Search and selected topic combine, with accessible empty/reset states.
- Long titles/URLs and doubled root text do not create horizontal overflow.
- Unknown citation IDs fail the build rather than create broken references.
- Rebuilding does not modify canonical research content.
